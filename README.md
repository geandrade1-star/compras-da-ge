# Controle de Compras

App pessoal da Ge para organizar gastos de cartão: cola o SMS do banco e ele
extrai valor, data, estabelecimento e cartão, categoriza e monta relatórios.

- **Os dados ficam só no aparelho de quem usa** (localStorage do navegador).
  Nada é enviado para servidor nenhum — este repositório guarda apenas o app.
- Backup e restauração em arquivo `.json`, pela aba Relatório.
- Funciona offline e dá para adicionar à tela de início do celular.

Arquivo único: `index.html`.
